# Shutdown Timer

![alt text](image.png)

Простое Windows-приложение для установки таймера автоматического выключения компьютера.

Приложение позволяет указать время до выключения в часах, минутах и секундах, после чего Windows автоматически выключит компьютер по истечении заданного времени.

## Возможности

- Установка таймера выключения компьютера.
- Выбор:
  - часов — от `00` до `23`;
  - минут — от `00` до `59`;
  - секунд — от `00` до `59`.

- Отображение обратного отсчёта.
- Отмена установленного таймера.
- Уведомление об ошибках.
- Тёмный интерфейс.
- Не требует установки дополнительных программ для использования. (не факт)

## Скачать и запустить

Для обычного использования не требуется устанавливать .NET или собирать проект самостоятельно.

1. Перейдите в папку `deploy`.
2. Переименуйте файл shutDown.exe в timer.exe (винде не нравится это название и может быть баг если оставите)
3. Запустите файл:

```text
timer.exe
```

Windows может запросить разрешение администратора — это необходимо для работы с системной командой выключения компьютера.

## Как пользоваться

### Установить таймер

1. Запустите `timer.exe`.
2. Выберите количество часов, минут и секунд.
3. Нажмите **«Запустить таймер»**.
4. Программа начнёт обратный отсчёт.
5. По окончании времени Windows автоматически выключит компьютер.

Например:

```text
Часы:   01
Минуты: 30
Секунды: 00
```

означает, что компьютер будет выключен через **1 час 30 минут**.

### Отменить таймер

Если таймер уже установлен, нажмите:

```text
Отменить
```

После этого автоматическое выключение будет отменено.
